# languages_learning
Học đa ngôn ngữ (Pháp · Trung · Anh)

Một file duy nhất: index.html. Không cần cài đặt, không cần lập trình.

Đưa lên GitHub Pages (khoảng 5 phút)
Đăng nhập github.com → bấm + (góc trên phải) → New repository.
Đặt tên (ví dụ hoc-ngoai-ngu), chọn Public (Pages miễn phí cần repo Public), bấm Create repository.
Bấm uploading an existing file, kéo index.html vào, bấm Commit changes.
Vào Settings → Pages. Ở mục Build and deployment: Source = Deploy from a branch, Branch = main, thư mục /(root), bấm Save.
Đợi 1–2 phút. Địa chỉ trang sẽ là https://TÊN-GITHUB.github.io/languages_learning/.
Trên iPad: mở bằng Safari → nút Chia sẻ → Thêm vào Màn hình chính để dùng như app.

Lưu ý: repo Public nghĩa là ai có link cũng xem được trang. Dữ liệu học của bạn KHÔNG nằm trong repo mà nằm trong trình duyệt của bạn.

Lưu ý quan trọng về dữ liệu
Dữ liệu lưu trong trình duyệt của từng thiết bị (không tự đồng bộ iPad ↔ máy tính).
Vào Trang chủ → Cài đặt để Tải file sao lưu thường xuyên; thiết bị khác thì Nhập file.
Thêm vào Màn hình chính giúp iPad ít xóa dữ liệu hơn, nhưng vẫn nên sao lưu.
Dùng hằng ngày
Quay lại / Trang chủ: hai nút ở góc trên trái mọi trang.
Thêm từ mới trong bài đọc: chạm từ chưa gạch chân → “Thêm từ này”; hoặc bôi đen cả cụm → nút “Thêm”. Từ lưu xong được gạch chân ngay.
Thêm bài từ sách: gửi trang sách cho Claude, nhờ trả JSON theo cấu trúc ở nút “Dán mẫu cấu trúc” (trang +), dán vào → Hộp nhận → Chấp nhận.
Cần kiểm chứng
IPA, phiên âm tiếng Việt do AI soạn: đối chiếu từ điển/audio.
Link chia động từ (Le Conjugueur) chưa kiểm tra từng động từ.
Dữ liệu trong bản này là bài mẫu tự viết, không phải nội dung giáo trình.
